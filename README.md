A plan an AI agent can carry out itself to turn $100 into the most money in 30 days: sell $29 AI product-photo packs to Etsy sellers, starting on day one by messaging 30 shops with weak photos and a free before/after sample, and growing to about $250 net by day 30.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (1–280 Unicode codepoints, deterministic).
