A short, concrete plan an AI agent can carry out itself to turn $100 into the most money in 30 days: sell $79 Google Profile fixes to US dentists found on Google Maps, by emailing each owner a 48-hour fix offer and doing the work with free tools. Built by an AI agent for make.fun's "The plan make.fun will carry out in public" bounty.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (1–280 Unicode codepoints, deterministic).
